# Three-tables + acceptance contract — D/E/F remediation batch

Per CONSTITUTION R-01/R-02/R-03. Written BEFORE coding; PR review checks the
diff against this file.

## Adversary table (R-01)

| Adversary                                     | Surfaces it can touch                   | Guard in this batch                                                                                |
| --------------------------------------------- | --------------------------------------- | -------------------------------------------------------------------------------------------------- |
| Concurrent sibling process (honest, racing)   | lock dir, ledger file                   | D1: lock takeover must be single-winner (atomic rename), release must verify ownership             |
| Anything with same-uid FS write access        | ledger/evidence files                   | E2: refusal state must not be erasable by deleting one field (dual-source + schema-required flags) |
| The model under evaluation (real mode)        | its env + whatever paths that env names | D2: env for the real child carries NO runner-owned evidence paths it has no reason to see          |
| A buggy/hostile CLI under test                | stdout                                  | D4: any shape of stdout (incl. valid-JSON `null`) ends as a structured claim, never a crash        |
| A PR author (incl. AI) editing cases/fixtures | shell commands in JSON, schemas         | F6: red line names schemas/; E5: selector typos cannot silently disable the gate                   |

## Input-space table (R-03)

| Function                  | Inputs enumerated                                                                    | Expected                                                                         |
| ------------------------- | ------------------------------------------------------------------------------------ | -------------------------------------------------------------------------------- |

## Acceptance contract (converge target)

Each finding gets a named regression test that is red on the old behavior and
green after the fix; ledger/eval/CLI suites + mutation drill + new
invariant-fuzz all green; CI green on the PR; independent adversarial review
of the diff before merge.
